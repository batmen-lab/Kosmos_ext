10. Loss / preprocessing switches (for reference)
--------------------------------------------------------------------------------
# loss:      --loss plain | signed | gold-plus-synthetic | gradient-gated
#            (env PPI_LOSS_MODE; the env value uses underscores)
#             signed              = PPI correction (has the negative term), the config default
#             plain               = pseudo-label distillation (needs soft targets, joint schedule)
#             gold-plus-synthetic = L_G + lambda*L_S, the naive baseline the gate replaces
#             gradient-gated      = g_G + lambda_t*g_S, lambda_t = max(0, cos(g_G,g_S))
#                                   * min(1, kappa*||g_G|| / ||g_S||)
# lambda:    --lambda 0.5                   (env PPI_LAMBDA)
# gate:      --gate-kappa 1.0 --gate-scope batch|sample --gate-gamma 1.0 --gate-lambda 1.0
#            (env PPI_GATE_KAPPA / PPI_GATE_SCOPE / PPI_GATE_GAMMA / PPI_GATE_LAMBDA;
#             the gate's own knobs live in ppi_summary.json -> training.gate and in
#             training_log.jsonl per epoch: cosine, weight, active fraction, grad norms)
# pseudo:    --pseudo-mode cross_fit|in_sample|pretrained
# single cell preprocessing (per source):
#   PPI_SINGLE_CELL_PREPROCESS=auto|on|off       PPI_SINGLE_CELL_TOP_GENES=2000
#   PPI_SINGLE_CELL_TARGET_SUM=10000             PPI_SINGLE_CELL_MIN_CELLS=3
#   PPI_SINGLE_CELL_FIGURES=true
# gating:    --min-shared-features 2 --min-shared-fraction 0.5
#            KOSMOS_ALLOW_CROSS_SPECIES=1  (only with a real ortholog mapping)
